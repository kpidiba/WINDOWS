# 🪟 Windows Software

Liste des logiciels Windows utilisés ou recommandés, classés par catégorie.

---

## 📁 Files & Transfers

| Software      | Description                                                   |
| ------------- | ------------------------------------------------------------- |
| **WinSCP**    | Transfert de fichiers sécurisé via **SFTP, SCP, FTP** et SSH. |
| **FileZilla** | Client **FTP / FTPS / SFTP** pour transférer des fichiers.    |
| **LocalSend** | Partage de fichiers entre appareils sur le **réseau local**.  |
| **WinRAR**    | Compression et décompression d'archives (`RAR`, `ZIP`, etc.). |
| **Recuva**    | Récupération de fichiers supprimés.                           |

---

## 📄 PDF & Documents

| Software     | Description                                                      |
| ------------ | ---------------------------------------------------------------- |
| **PDFgear**  | Lecture et édition de fichiers PDF.                              |
| **iLovePDF** | Outils PDF : fusion, division, conversion, compression, etc.     |
| **PDFsam**   | Fusion, division, rotation et organisation de fichiers PDF.      |
| **NAPS2**    | Numérisation de documents et création de PDF.                    |
| **draw.io**  | Création de diagrammes, schémas, organigrammes et architectures. |

---

## 📧 Communication

| Software        | Description                                              |
| --------------- | -------------------------------------------------------- |
| **Thunderbird** | Client de messagerie pour gérer plusieurs comptes email. |
| **AnyDesk**     | Accès et assistance à distance sur un ordinateur.        |

---

## 💻 Development & Administration

| Software     | Description                                                        |
| ------------ | ------------------------------------------------------------------ |
| **Insomnia** | Test et développement d'API **REST / GraphQL**.                    |
| **PuTTY**    | Client **SSH, Telnet et série** pour l'administration de systèmes. |

---
